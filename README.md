# Suede.vsix.format On Save

This repo is a [suede dependency](https://github.com/pmalacho-mit/suede). 

To see the installable source code, please checkout the [release branch](https://github.com/pmalacho-mit/suede.vsix.format-on-save/tree/release).

## Installation

```bash
bash <(curl -fsSL https://suede.sh/install/release) --repo pmalacho-mit/suede.vsix.format-on-save --dev
```

Run it where you want the dependency. It installs `./suede.vsix.format-on-save`, stages it, and prints
what else (if anything) has to be installed beside it.
